# 5.2. Playdate Lua API conventions

## Arrays
Lua-Arrays sind 1-basiert. Arrays sind spezielle Tabellen und können keine `nil`-Werte enthalten.

## Funktionsaufrufe
- Klassen-/Tabellenfunktionen: `myTable.function(a, b, c)`
- Instanzfunktionen: `myObject:function(a, b, c)` (überträgt das Objekt als `self`)

## Rückgabewerte
Manche APIs liefern Objekte, andere mehrere Werte. Beispiel:

```lua
r1 = playdate.geometry.rect.new(5, 5, 10, 10)
r2 = playdate.geometry.rect.new(8, 8, 10, 10)
intersection = r1:intersection(r2)
print(intersection.x, intersection.y, intersection.width, intersection.height)

x, y, w, h = playdate.geometry.rect.fast_intersection(5, 8, 5, 8, 10, 10, 10, 10)
print(x, y, w, h)
```
