# 4. Writing a game

## 4.1. Choosing your development language

Die meisten Playdate-Spiele werden aus Gründen der Einfachheit in Lua geschrieben, aber Spiele mit besonders hohen Performance-Anforderungen können teilweise oder vollständig in C geschrieben werden. Siehe die zugehörigen Abschnitte für weitere Informationen zur richtigen Wahl.

## 4.2. Structuring your project

Lege alle Skripte und Assets in einem einzigen Projektverzeichnis ab. Dein Quellverzeichnis muss mindestens ein Lua-Skript namens `main.lua` enthalten. Dieses Skript kann bei Bedarf weitere Skripte über den Befehl `import` einbinden. Der Playdate-Runtime verwendet `import` anstelle der Standardfunktion `require` von Lua und verhält sich dabei etwas anders: Alle Dateien, die von main.lua (und rekursiv von dort importierten Dateien) importiert werden, werden zu einer einzigen pdz-Datei kompiliert. Ein zweiter Import derselben Datei hat keine Wirkung.

Beispielstruktur:

```
[Projektname]/
    source/
        main.lua
        ...weitere .lua-Dateien
        images/
            ...Bilddateien...
        sounds/
            ...Audiodateien...
    support/
        ...Projektdateien, z.B. Photoshop-Assets...
```

- Lua-Datei importieren: `import "myLuaFile"`
- Bild laden: `myImage = playdate.graphics.image.new("images/myImageFile")`
- Sound laden: `mySound = playdate.sound.sampleplayer.new("sounds/mySoundFile")`
- Objektorientierte Klasse anlegen:

```
import "A"
class("B").extends(A)

function B:init()
    B.super.init(self)
    -- Initialisierungscode
end
```

Verwende überall Vorwärtsschrägstriche `/` als Pfadtrenner. Backslashes `\` funktionieren nur im Windows-Simulator, nicht auf dem Gerät.
