# 2. Contents of the SDK

Dieses SDK enthält:

- Softwaretools zum Kompilieren deines Spiels
- Einen Gerätesimulator zum Testen deines Spiels
- Eine Bibliothek mit häufig verwendeten Funktionen
- Einige Schriftarten und andere Assets
- Beispielcode und Beispielspiele
- Dokumentation

---

**Originaltext (englisch):**

This SDK contains:

- Software tools to compile your game
- A device Simulator to test your game
- A set of libraries for common functions you can use in your game
- Some fonts and other assets you can use in your game
- Some example code and games
- Documentation
