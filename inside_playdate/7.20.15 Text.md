### Text

### Fonts

Playdate-Fonts sind Objekte vom Typ `playdate.graphics.font`, die mit `playdate.graphics.font.new(path)` geladen und mit `playdate.graphics.drawText(text, x, y)` gezeichnet werden.

Der Compiler kann eine Schriftart aus einer eigenständigen .fnt-Datei mit eingebetteten Bilddaten oder durch Kombination einer abhängigen .fnt-Datei mit einer zugehörigen Image Table erzeugen. Beispiel: Für awesomefont.fnt heißt die zugehörige Image Table awesomefont-table-9-12.png.

Eigenständige .fnt-Dateien können mit dem Playdate Caps Web-Tool erstellt werden.

Eine abhängige .fnt-Datei enthält pro Glyphen eine Zeile: das Zeichen ("space" für Leerzeichen), in der Reihenfolge wie im Image Table, und die Breite, getrennt durch beliebig viele Leerzeichen. Unicode _U+xxxx_ wird unterstützt.

Beispielauszug .fnt-Datei:

```
space	6
!	2
"	4
#	7
```

Leere Zeilen werden ignoriert. Kommentare beginnen mit zwei Bindestrichen.

```
$	6
%	8
-- dieser Kommentar wird ignoriert
&	7
```

Optional kann ein Standard-Tracking-Wert angegeben werden:

```
tracking = 2
```

Tracking ist der Abstand in Pixeln zwischen den Zeichen.

Kerning-Paare werden unterstützt, z.B.:

```
To	-2
ll	3
bU+20	-1
```

Eigenständige .fnt-Dateien benötigen zusätzliche Eigenschaften: `datalen` (Länge der base64-kodierten Bilddaten), `data` (base64-kodierte Image Table), `width` und `height` (Pixelmaße der Zellen).

```
datalen=8984
data=iVBO...YII=
width=8
height=12
```

Playdate Caps kann außerdem Metriken als JSON-Kommentar einbetten:

```
--metrics={"baseline":17,"xHeight":6,"capHeight":2}
```

### Unterstützte Zeichen

Alle Codepoints der ersten vier Unicode-Ebenen bis U+3FFFF werden unterstützt. Ist ein Ersatzzeichen angegeben, wird dieses für fehlende Zeichen verwendet, sonst das Systemfont.

### Varianten

Für Formatierung und Lokalisierung können bis zu drei Font-Dateien als Varianten (normal, fett, kursiv) angegeben werden.

### Font-Klassenfunktionen

#### playdate.graphics.font.new(path)
Lädt eine Schriftart aus der Datei unter `path`. Gibt ein Font-Objekt zurück oder nil, falls nicht gefunden.

#### playdate.graphics.font.newFamily(fontPaths)
Erstellt eine Font-Familie aus mehreren Font-Dateien. Beispiel:

```lua
local fontPaths = {
    [playdate.graphics.font.kVariantNormal] = "path/to/normalFont",
    [playdate.graphics.font.kVariantBold] = "path/to/boldFont",
    [playdate.graphics.font.kVariantItalic] = "path/to/italicFont"
}
```

#### playdate.graphics.setFont(font, [variant])
Setzt die aktuelle Schriftart. `variant` ist "normal", "bold" oder "italic" (bzw. die entsprechenden Konstanten). Standard ist "normal".

#### playdate.graphics.getFont([variant])
Gibt die aktuelle Schriftart zurück.

#### playdate.graphics.setFontFamily(fontFamily)
Setzt mehrere Font-Varianten gleichzeitig. Beispiel:

```lua
local fontFamily = {
    [playdate.graphics.font.kVariantNormal] = normal_font,
    [playdate.graphics.font.kVariantBold] = bold_font,
    [playdate.graphics.font.kVariantItalic] = italic_font
}
```

#### playdate.graphics.setFontTracking(pixels)
Setzt das globale Tracking (Buchstabenabstand) in Pixeln. Wird zum Tracking aus der .fnt-Datei addiert.

#### playdate.graphics.getFontTracking()
Gibt das globale Tracking zurück.

#### playdate.graphics.getSystemFont([variant])
Gibt das Systemfont zurück.

### Font-Instanzfunktionen

#### playdate.graphics.font:drawText(text, x, y, [width, height], [leadingAdjustment], [wrapMode], [alignment])
Zeichnet einen Text an die Position x, y mit dieser Schriftart. Optional kann ein Rechteck, Zeilenabstand, Umbruchmodus und Ausrichtung angegeben werden. Rückgabe: Breite und Höhe des gezeichneten Texts.

**Hinweis:** `font:drawText()` unterstützt keine Inline-Styles wie fett oder kursiv. Dafür `playdate.graphics.drawText()` verwenden.

#### playdate.graphics.font:drawTextAligned(text, x, y, alignment, [leadingAdjustment])
Zeichnet den Text links-, rechts- oder zentriert an x. **Wichtig:** _CoreLibs/graphics_ muss importiert sein.

#### playdate.graphics.font:getHeight()
Gibt die Pixelhöhe der Schriftart zurück.

#### playdate.graphics.font:getTextWidth(text)
Gibt die Pixelbreite des Textes zurück.

#### playdate.graphics.font:setTracking(pixels)
Setzt das Tracking (Buchstabenabstand) für diese Schriftart.

#### playdate.graphics.font:getTracking()
Gibt das Tracking der Schriftart zurück.

#### playdate.graphics.font:setLeading(pixels)
Setzt den Zeilenabstand (Leading) für diese Schriftart.

#### playdate.graphics.font:getLeading()
Gibt den Zeilenabstand zurück.

#### playdate.graphics.font:getGlyph(character)
Gibt das Bild für das angegebene Zeichen zurück.

### Text zeichnen

#### playdate.graphics.drawText(text, x, y, [width, height], [fontFamily], [leadingAdjustment], [wrapMode], [alignment])
Zeichnet Text mit der aktuellen Schriftart an Position x, y. Optional kann ein Rechteck, Font-Familie, Zeilenabstand, Umbruchmodus und Ausrichtung angegeben werden. Rückgabe: Breite und Höhe des gezeichneten Texts.

**Text-Formatierung:** Fett mit *Text*, kursiv mit _Text_. Beispiel:

```lua
playdate.graphics.drawText("normal *fett* _kursiv_", x, y)
```

**Escaping:** Um * oder _ zu zeichnen, doppelt schreiben (** oder __). Styles können nicht verschachtelt werden.

**Kein Styling:** Mit `playdate.graphics.font:drawText()` wird Text immer unformatiert gezeichnet.

**Invertierte Textfarbe:** Erst `playdate.graphics.setImageDrawMode(playdate.graphics.kDrawModeFillWhite)` aufrufen, dann Text zeichnen.

**playdate.graphics.drawLocalizedText(key, x, y, [width, height], [language], [leadingAdjustment], [wrapMode], [alignment])**

Zeichnet Text aus einer .strings-Datei für die aktuelle Sprache. Sprache kann als "en", "jp" oder als Konstante angegeben werden.

**playdate.graphics.getLocalizedText(key, [language])**

Gibt einen lokalisierten String zurück.

**playdate.graphics.getTextSize(str, [fontFamily, [leadingAdjustment]])**

Gibt die Breite und Höhe zurück, die zum Zeichnen von str benötigt werden.

#### playdate.graphics.drawTextAligned(text, x, y, alignment, [leadingAdjustment])
Zeichnet Text links-, rechts- oder zentriert an x. **Wichtig:** _CoreLibs/graphics_ muss importiert sein.

#### playdate.graphics.drawTextInRect(text, x, y, width, height, [leadingAdjustment, [truncationString, [alignment, [font]]]])
Zeichnet Text in das angegebene Rechteck. Wenn truncationString angegeben ist, wird dieser angehängt, falls der Text nicht passt. Rückgabe: Breite, Höhe, ob Text gekürzt wurde.

#### playdate.graphics.drawLocalizedTextAligned(text, x, y, alignment, [language, [leadingAdjustment]])
Wie drawTextAligned, aber für lokalisierten Text.

#### playdate.graphics.drawLocalizedTextInRect(text, x, y, width, height, [leadingAdjustment, [truncationString, [alignment, [font, [language]]]]])
Wie drawTextInRect, aber für lokalisierten Text.

#### playdate.graphics.getTextSizeForMaxWidth(text, maxWidth, [leadingAdjustment, [font]])
Gibt die minimale Größe zurück, die zum Zeichnen von text mit drawTextInRect benötigt wird. Die Breite ist maximal maxWidth.

#### playdate.graphics.imageWithText(text, maxWidth, maxHeight, [backgroundColor, [leadingAdjustment, [truncationString, [alignment, [font]]]]])
Erzeugt ein Bild mit dem angegebenen Text. Praktisch, wenn derselbe Text häufig gezeichnet werden soll. Rückgabe: Bild und ob Text gekürzt wurde.
