# 1.1. Playdate specifications

**Display**
- Monochromes (1-Bit) Memory-LCD-Display
- 400 x 240 Pixel Auflösung
- Standardmäßig 30 Bilder pro Sekunde, maximal 50 fps

**Steuerung**
- Acht-Wege-Steuerkreuz (D-Pad)
- Zwei Haupttasten
- Menütaste
- Sperrtaste
- Ausklappbare Kurbel
- Beschleunigungssensor

**Sound**
- Interner Lautsprecher
- Mikrofon
- Kopfhöreranschluss mit Mikrofoneingang

**Konnektivität**
- WLAN
- Bluetooth

**Speicher**
- 16MB RAM
- 4GB Flash-Speicher

---

**Originaltext (englisch):**

Display

- Monochrome (1-bit) memory LCD display
- 400 x 240 pixel resolution
- Refreshed at 30 frames-per-second (fps) by default, maximum 50 fps

Controls

- Eight-way directional control (D-pad)
- Two primary buttons
- Menu button
- Lock button
- Collapsible crank
- Accelerometer

Sound

- Internal speaker
- Microphone
- Headphone jack supporting mic input

Connectivity

- Wi-Fi
- Bluetooth

Memory & Storage

- 16MB RAM
- 4GB flash storage
