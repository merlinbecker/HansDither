a.s = 1.9

### playdate.graphics.animation.loop
Hilft beim Verwalten von Animations-Frames, besonders für Frames in einem playdate.graphics.imagetable. Für allgemeinere Timer siehe playdate.timer oder playdate.frameTimer.

**Important:** Du musst CoreLibs/animation importieren, um diese Funktionen zu verwenden.

### playdate.graphics.animation.loop.new([interval], imageTable, [shouldLoop])
Erzeugt ein neues Animationsobjekt.

- imageTable muss ein playdate.graphics.imagetable oder ein Array von playdate.graphics.images sein.

Die folgenden Properties können direkt gelesen oder gesetzt werden (Standardwerte):
- interval: Wert von interval oder 100ms (Zeit pro Frame)
- startFrame: 1 (Startwert beim Loop)
- endFrame: Anzahl der Bilder in imageTable oder 1 (letzter Frame)
- frame: 1 (aktueller Frame-Zähler)
- step: 1 (Schrittweite)
- shouldLoop: Wert von shouldLoop oder true (ob die Animation looped)
- paused: false (pausierte Loops ändern den Frame nicht)

### playdate.graphics.animation.loop:draw(x, y, [flip])
Zeichnet das aktuelle Bild der Animation an (x, y). Der Parameter flip ist optional.

### playdate.graphics.animation.loop:image()
Gibt das aktuelle Bild (playdate.graphics.image) aus dem imageTable zurück, passend zum aktuellen Frame.

### playdate.graphics.animation.loop:isValid()
Gibt false zurück, wenn der Loop den letzten Frame überschritten hat und nicht looped.

### playdate.graphics.animation.loop:setImageTable(imageTable)
Setzt das imageTable für diesen Animationsloop und passt endFrame entsprechend an.

#### Beispiel: Animationsloop für ein animiertes Bild
```lua
local gfx = playdate.graphics

-- Jede Animationsstufe dauert 200ms
local frameTime = 200
local animationImagetable = gfx.imagetable.new("path/to/imagetable")
-- true sorgt dafür, dass die Animation looped
local animationLoop = gfx.animation.loop.new(frameTime, animationImagetable, true)

function playdate.update()
    animationLoop:draw(0, 0)
end
```

#### Beispiel: Mehrere Animationszustände aus einem Sprite Sheet
```lua
local gfx = playdate.graphics

local animationImagetable = gfx.imagetable.new("path/to/imagetable")

local idleAnimation = gfx.animation.loop.new(400, animationImagetable, true)
idleAnimation.startFrame = 1
idleAnimation.endFrame = 3

local runAnimation = gfx.animation.loop.new(200, animationImagetable, true)
runAnimation.startFrame = 4
runAnimation.endFrame = 8

local states = {idle = 1, run = 2}
local state = states.idle

function playdate.update()
    if state == states.idle then
        idleAnimation:draw(0, 0)
    elseif state == states.run then
        runAnimation:draw(0, 0)
    end
end
```

#### Beispiel: Animationsloop in einem Sprite
```lua
local gfx = playdate.graphics

local frameTime = 200
local animationImagetable = gfx.imagetable.new("path/to/imagetable")
local animationLoop = gfx.animation.loop.new(frameTime, animationImagetable, false)
local animatedSprite = gfx.sprite.new(animationLoop:image())
animatedSprite:add()
animatedSprite.update = function()
    animatedSprite:setImage(animationLoop:image())
    if not animationLoop:isValid() then
        animatedSprite:remove()
    end
end
```

### playdate.graphics.animator
Animators sind leichte Objekte, die den Fortschritt einer Animation verwalten. Sie können zwischen zwei Zahlen, zwei Punkten, entlang eines Liniensegments, Bogens oder Polygons oder entlang eines zusammengesetzten Pfads animieren.

**Important:** Du musst CoreLibs/animator importieren, um diese Funktionen zu verwenden.

### playdate.graphics.animator.new(duration, startValue, endValue, [easingFunction, [startTimeOffset]])
Animiert zwischen zwei Zahlen oder playdate.geometry.point-Werten.
- duration: Gesamtdauer in Millisekunden
- startValue, endValue: Zahlen oder Punkte
- easingFunction (optional): Wert aus playdate.easingFunctions
- startTimeOffset (optional): Startzeitverschiebung in ms

Wenn die easingFunction zusätzliche Variablen benötigt (s, a, p), können diese nachträglich gesetzt werden:
```lua
local a = playdate.graphics.animator.new(1000, 0, 100, playdate.easingFunctions.inBack)
a.s = 1.9
```

#### Beispiel: Bewegung animieren
```lua
import "CoreLibs/graphics"
import "CoreLibs/animator"

local square = playdate.graphics.image.new(20, 20, playdate.graphics.kColorBlack)
local animationDuration = 1000
local startX, endX = -20, 400
local easingFunction = playdate.easingFunctions.inOutCubic
local animator = playdate.graphics.animator.new(animationDuration, startX, endX, easingFunction)
animator.repeatCount = -1 -- Endlosschleife

function playdate.update()
    playdate.graphics.clear()
    square:draw(animator:currentValue(), 120)
end
```

### playdate.graphics.animator.new(duration, lineSegment, [easingFunction, [startTimeOffset]])
Animiert entlang eines playdate.geometry.lineSegment.

#### Beispiel: Animation entlang einer Linie
```lua
import "CoreLibs/graphics"
import "CoreLibs/animator"

local square = playdate.graphics.image.new(20, 20, playdate.graphics.kColorBlack)
local animationDuration = 1000
local line = playdate.geometry.lineSegment.new(0, 0, 400, 240)
local animator = playdate.graphics.animator.new(animationDuration, line)

function playdate.update()
    playdate.graphics.clear()
    square:draw(animator:currentValue())
end
```

### playdate.graphics.animator.new(duration, arc, [easingFunction, [startTimeOffset]])
Animiert entlang eines playdate.geometry.arc.

### playdate.graphics.animator.new(duration, polygon, [easingFunction, [startTimeOffset]])
Animiert entlang eines playdate.geometry.polygon.

### playdate.graphics.animator.new(durations, parts, easingFunctions, [startTimeOffset])
Animiert entlang mehrerer Teile (lineSegment, arc, polygon), die in parts als Array übergeben werden. durations und easingFunctions sind Arrays gleicher Länge.

**Hinweis:** Standardmäßig wiederholen sich Animators nicht. Setze repeatCount auf die gewünschte Anzahl oder -1 für Endlosschleife. repeatCount = 1 bedeutet: Animation läuft zweimal (einmal initial, einmal Wiederholung).

#### Beispiel: Animation mit mehreren Teilen
```lua
import "CoreLibs/graphics"
import "CoreLibs/animator"

local square = playdate.graphics.image.new(20, 20, playdate.graphics.kColorBlack)
local animationDurations = {3000, 1000, 2000}
local animationParts = {
    playdate.geometry.lineSegment.new(0, 0, 200, 80),
    playdate.geometry.arc.new(200, 120, 40, 0, 180),
    playdate.geometry.polygon.new(200, 160, 300, 90, 390, 230)
}
local animationEasingFunctions = {
    playdate.easingFunctions.outQuart,
    playdate.easingFunctions.inOutCubic,
    playdate.easingFunctions.outBounce
}
local animator = playdate.graphics.animator.new(animationDurations, animationParts, animationEasingFunctions)

function playdate.update()
    playdate.graphics.clear()
    square:draw(animator:currentValue())
end
```

### playdate.graphics.animator:currentValue()
Gibt den aktuellen Wert der Animation zurück (Zahl oder Punkt, je nach Animator).

### playdate.graphics.animator:valueAtTime(time)
Gibt den Wert der Animation nach time Millisekunden seit Start zurück.

### playdate.graphics.animator:progress()
Gibt den aktuellen Fortschritt der Animation als Wert von 0 bis 1 zurück.

### playdate.graphics.animator:reset([duration])
Setzt die Animation zurück, Startzeit ist jetzt, Dauer kann geändert werden.

### playdate.graphics.animator:ended()
Gibt true zurück, wenn die Animation abgeschlossen ist. Nur true, wenn diese Funktion oder currentValue() nach Ende aufgerufen wurde.

### playdate.graphics.animator.repeatCount
Anzahl der Wiederholungen nach der Initialanimation (2 = insgesamt 3 Durchläufe).

### playdate.graphics.animator.reverses
Wenn true, läuft die Animation nach dem Ende rückwärts zurück. Die Gesamtdauer ist dann duration x 2. Standard: false.

## playdate.graphics.animation.blinker
Verwaltet einen booleschen Wert, der auf einem Timer wechselt.

**Important:** Du musst CoreLibs/animation importieren, um blinker zu verwenden.

### playdate.graphics.animation.blinker.new([onDuration, [offDuration, [loop, [cycles, [default]]]]])
Erzeugt ein neues Blinker-Objekt. Über die on-Property kann abgefragt werden, ob der Blinker gerade an (true) oder aus (false) ist. Standardwerte:
- onDuration: 200 (Millisekunden an)
- offDuration: 200 (Millisekunden aus)
- loop: false (ob der Blinker neu startet)
- cycles: 6 (wie oft der Blinker wechselt, bevor er fertig ist)
- default: true (Startzustand; ist default true, ist blinker.on während onDuration true, sonst false)

Weitere Properties:
- counter: aktueller Zyklus (zählt von n auf 0)
- on: aktueller Zustand
- running: ob der Blinker aktiv ist

### playdate.graphics.animation.blinker.updateAll()
Aktualisiert den Zustand aller gültigen Blinker (sollte einmal pro Zyklus, idealerweise in playdate.update(), aufgerufen werden).

### playdate.graphics.animation.blinker:update()
Aktualisiert den Zustand des Blinkers.

### playdate.graphics.animation.blinker:start([onDuration, [offDuration, [loop, [cycles, [default]]]]])
Startet den Blinker, falls er nicht läuft. Werte können zum Überschreiben übergeben werden.

### playdate.graphics.animation.blinker:startLoop()
Startet den Blinker und setzt loop auf true (wie start(nil, nil, true)).

### playdate.graphics.animation.blinker:stop()
Stoppt den Blinker und setzt on auf den Defaultwert zurück.

### playdate.graphics.animation.blinker.stopAll()
Stoppt alle Blinker.

### playdate.graphics.animation.blinker:remove()
Markiert den Blinker zur Entfernung aus der globalen Blinker-Liste.
