# 5.4. Object-oriented programming in Lua

Lua bietet keine eingebaute OOP-Unterstützung, aber CoreLibs stellt ein einfaches Klassensystem bereit. Beispiel:

```lua
class('Tree').extends()
class('Oak').extends(Tree)

function Oak:init(age, height)
    Oak.super.init(self, age)
    self.height = height
end

oakInstance = Oak(5, 10)
print(oakInstance.className) -- 'Oak'
print(oakInstance:isa(Tree)) -- true
```

`Object:tableDump()` gibt alle Schlüssel/Werte des Objekts und seiner Superklassen aus.
