# 5.3. Lua Tips

## Variablen mit `local` initialisieren
Immer `local` verwenden, um Variablen auf den aktuellen Block zu beschränken. Globale Variablen sind langsamer und können zu Fehlern führen.

## Häufig genutzte Objekte lokal speichern
Zugriffe auf z.B. `playdate.graphics` werden schneller, wenn du sie einer lokalen Variable zuweist:

```lua
local gfx <const> = playdate.graphics
...
gfx.setColor(gfx.kColorWhite)
gfx.drawRect(14, 14, 22, 22)
```
