
### 7.21. JSON

Stellt Funktionen zum Kodieren und Dekodieren von JSON-Dateien und -Strings bereit.

### json.decode(string)
Wandelt einen JSON-codierten String in eine Lua-Tabelle um.

**Beispiel:**
```lua
local t = json.decode('{"score": 100, "name": "Hans"}')
print(t.score) -- 100
```

### json.encode(table)
Gibt einen String mit der JSON-Repräsentation der übergebenen Lua-Tabelle zurück.

**Beispiel:**
```lua
local t = {score = 100, name = "Hans"}
local s = json.encode(t)
print(s) -- {"score":100,"name":"Hans"}
```

### json.encodePretty(table)
Wie `json.encode`, aber das Ergebnis ist menschenlesbar formatiert.

### json.encodeToFile(file/path, [pretty], table)
Kodiert die Lua-Tabelle als JSON und schreibt sie in die angegebene Datei (entweder ein playdate.file.file-Objekt oder ein Pfad). Ist _pretty_ true, wird das JSON lesbar formatiert, sonst kompakt.

**Tipp:** Für sehr einfaches Serialisieren einer Tabelle in eine Datei siehe auch playdate.datastore.
