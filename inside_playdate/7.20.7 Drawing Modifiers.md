
### playdate.graphics.setClipRect(x, y, width, height)
### playdate.graphics.setClipRect(rect)
Setzt das Clipping-Rechteck für alle nachfolgenden Grafikoperationen, einschließlich Bitmaps. Das Argument kann entweder einzelne Werte oder ein playdate.geometry.rect-Objekt sein. Das Clipping-Rechteck wird zu Beginn von playdate.update() automatisch zurückgesetzt. Die Funktion verwendet Weltkoordinaten (wird also durch den aktuellen Zeichenoffset verschoben). Für Bildschirmkoordinaten verwende setScreenClipRect().

Entspricht playdate->graphics->setClipRect() in der C API.

### playdate.graphics.getClipRect()
Gibt die aktuellen Werte (x, y, width, height) des Clipping-Rechtecks zurück.

### playdate.graphics.setScreenClipRect(x, y, width, height)
### playdate.graphics.setScreenClipRect(rect)
Setzt das Clipping-Rechteck wie oben, verwendet aber Bildschirmkoordinaten (ignoriert also den Zeichenoffset).

Entspricht playdate->graphics->setScreenClipRect() in der C API.

### playdate.graphics.getScreenClipRect()
Gibt das aktuelle Clipping-Rechteck in Bildschirmkoordinaten zurück.

### playdate.graphics.clearClipRect()
Hebt das aktuelle Clipping-Rechteck auf, das mit setClipRect() gesetzt wurde.

Entspricht playdate->graphics->clearClipRect() in der C API.

### playdate.graphics.setStencilImage(image, [tile])
Setzt das aktuelle Stencil auf das angegebene Bild. Solange das Stencil aktiv ist, zeichnen Zeichenfunktionen nur dort, wo das Stencil weiß ist. Ist tile gesetzt, wird das Stencil gekachelt (Bildbreite muss dann ein Vielfaches von 32 Pixeln sein).

Entspricht playdate->graphics->setStencilImage() in der C API.

### playdate.graphics.setStencilPattern(pattern)
Setzt ein Muster für das Stencil-Drawing. pattern ist eine Tabelle der Form { row1, row2, ..., row8 }.

### playdate.graphics.setStencilPattern(row1, row2, row3, row4, row5, row6, row7, row8)
Alternative Übergabe des Musters als einzelne Zeilen.

### playdate.graphics.setStencilPattern(level, [ditherType])
Setzt das Stencil auf ein Dithermuster, das durch level und optional ditherType (Standard: playdate.graphics.image.kDitherTypeBayer8x8) bestimmt wird.

### playdate.graphics.setImageDrawMode(mode)
Setzt den aktuellen Zeichenmodus für Bilder.

**Important:** Der Zeichenmodus gilt für Bilder und Fonts (da Fonts technisch Bilder sind). Primitive Formen wie Linien oder Rechtecke sind davon nicht betroffen.

Mögliche Werte für mode:
- playdate.graphics.kDrawModeCopy: Bilder werden exakt gezeichnet (schwarz bleibt schwarz, weiß bleibt weiß)
- playdate.graphics.kDrawModeWhiteTransparent: Weiße Bildbereiche werden transparent gezeichnet
- playdate.graphics.kDrawModeBlackTransparent: Schwarze Bildbereiche werden transparent gezeichnet
- playdate.graphics.kDrawModeFillWhite: Alle nicht-transparenten Pixel werden weiß gezeichnet
- playdate.graphics.kDrawModeFillBlack: Alle nicht-transparenten Pixel werden schwarz gezeichnet
- playdate.graphics.kDrawModeXOR: Pixel werden invertiert auf weißem Hintergrund gezeichnet
- playdate.graphics.kDrawModeNXOR: Pixel werden invertiert auf schwarzem Hintergrund gezeichnet
- playdate.graphics.kDrawModeInverted: Pixel werden invertiert (schwarz wird weiß, weiß wird schwarz)

Statt der Konstanten können auch die Strings "copy", "inverted", "XOR", "NXOR", "whiteTransparent", "blackTransparent", "fillWhite" oder "fillBlack" verwendet werden.

Entspricht playdate->graphics->setDrawMode() in der C API.

### playdate.graphics.getImageDrawMode()
Gibt den aktuellen Zeichenmodus für Bilder zurück.

### playdate.graphics.setLineWidth(width)
Setzt die Linienbreite für drawLine, drawRect, drawPolygon und drawArc (bei Übergabe eines playdate.geometry.arc). Der Wert wird beim Pushen und Poppen des Grafik-Kontexts gespeichert und wiederhergestellt.

### playdate.graphics.getLineWidth()
Gibt die aktuelle Linienbreite zurück.

### playdate.graphics.setStrokeLocation(location)
Legt fest, wo der Rand (Stroke) relativ zum Rechteck bei drawRect gezeichnet wird.
location ist einer der Werte:
- playdate.graphics.kStrokeCentered
- playdate.graphics.kStrokeOutside
- playdate.graphics.kStrokeInside
Auch dieser Wert wird beim Pushen und Poppen des Grafik-Kontexts gespeichert und wiederhergestellt.

### playdate.graphics.getStrokeLocation()
Gibt die aktuelle Stroke-Position zurück.
