# 5.5. CoreLibs

CoreLibs ist eine Sammlung optionaler Lua-Bibliotheken für Playdate, z.B. für Sprites, Timer, Animationen und Kollisionserkennung. Jede Bibliothek muss explizit importiert werden, z.B.:

```lua
import "CoreLibs/sprites"
```

Die Dokumentation zu CoreLibs befindet sich im SDK-Ordner `CoreLibs`.
